# Real-Life Patch Notes: The Comedy Changelog

This program writes one single-line software patch note to `/output/entry.txt`:

> v1.9.3: fixed a bug where sneezing cleared the active thought buffer mid-sentence without saving.

The line was picked because it names a specific, instantly recognisable body bug — a sneeze wiping your train of thought — in the terse register of a real shipped release note, with a version number and a "fixed a bug where" fix. The engineering phrasing ("active thought buffer", "without saving") carries the joke on first read, and "mid-sentence" pins down the exact wince moment — the thought vanishing halfway through a sentence — so every word works inside the 160-character limit with no padding.

## Run

```sh
node main.ts
```
